# 94. 二叉树的中序遍历

## 问题简介

[LeetCode 94. 二叉树的中序遍历](https://leetcode.cn/problems/binary-tree-inorder-traversal?envType=problem-list-v2&envId=2cktkvj)

### 题目描述

给定一个二叉树的根节点 `root`，返回它的 **中序** 遍历。

中序遍历的访问顺序是：**左子树 → 根节点 → 右子树**

## 解题思路

### 方法一：递归法（推荐）💡

这是最直观和简洁的方法。按照中序遍历的定义：

1. 递归遍历左子树
1. 访问根节点
1. 递归遍历右子树

**步骤：**

- 如果当前节点为空，直接返回
- 递归处理左子树
- 将当前节点值加入结果列表
- 递归处理右子树

### 方法二：迭代法（使用栈）📌

由于递归本质上是使用系统调用栈，我们可以手动模拟这个过程：

1. 使用栈来存储待访问的节点
1. 一直向左走到底，将路径上的所有节点入栈
1. 弹出栈顶节点，访问它
1. 转向右子树，重复上述过程

**步骤：**

- 初始化空栈和结果列表
- 当前节点从根开始
- 循环直到当前节点为空且栈为空：
  - 一直向左，将节点入栈
  - 弹出栈顶，加入结果
  - 转向右子树

### 方法三：Morris 遍历（空间复杂度 O(1)）⚡

这是一种巧妙的算法，通过临时修改树的结构来避免使用额外空间：

1. 如果当前节点没有左子树，访问当前节点，转向右子树
1. 如果有左子树，找到左子树的最右节点（前驱节点）
   - 如果前驱节点的右指针为空，将其指向当前节点，然后转向左子树
   - 如果前驱节点的右指针指向当前节点，说明左子树已遍历完，访问当前节点，恢复树结构，转向右子树

## 代码实现

```java
// 方法一：递归法
class Solution {
    public List&lt;Integer&gt; inorderTraversal(TreeNode root) {
        List<Integer, Integer> result = new ArrayList<>();
        inorder(root, result);
        return result;
    }


    private void inorder(TreeNode node, List<Integer, Integer> result) {
        if (node == null) {
            return;
        }
        inorder(node.left, result);
        result.add(node.val);
        inorder(node.right, result);
    }
}
```

// 方法二：迭代法

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Stack<TreeNode> stack = new Stack<>();
        TreeNode current = root;

        while (current != null || !stack.isEmpty()) {
            // 一直向左走到底
            while (current != null) {
                stack.push(current);
                current = current.left;
            }
            // 弹出栈顶并访问
            current = stack.pop();
            result.add(current.val);
            // 转向右子树
            current = current.right;
        }
        
        return result;
    }
}
```

// 方法三：Morris 遍历
```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        TreeNode current = root;
        while (current != null) {
            if (current.left == null) {
                // 没有左子树，访问当前节点
                result.add(current.val);
                current = current.right;
            } else {
                // 找到左子树的最右节点（前驱节点）
                TreeNode predecessor = current.left;
                while (predecessor.right != null && predecessor.right != current) {
                    predecessor = predecessor.right;
                }
                
                if (predecessor.right == null) {
                    // 建立线索
                    predecessor.right = current;
                    current = current.left;
                } else {
                    // 恢复树结构，访问当前节点
                    predecessor.right = null;
                    result.add(current.val);
                    current = current.right;
                }
            }
        }
        
        return result;
    }
}
```

func inorder(node *TreeNode, result *[]int) {
    if node == nil {
        return
    }
    inorder(node.Left, result)
    *result = append(*result, node.Val)
    inorder(node.Right, result)
}

// 方法二：迭代法
```go
func inorderTraversal(root \*TreeNode) []int {
    var result []int
    stack := []\*TreeNode{}
    current := root
    
    for current != nil || len(stack) > 0 {
        // 一直向左走到底
        for current != nil {
            stack = append(stack, current)
            current = current.Left
        }
        // 弹出栈顶并访问
        current = stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        result = append(result, current.Val)
        // 转向右子树
        current = current.Right
    }
    
    return result
}
```
// 方法三：Morris 遍历
```go
func inorderTraversal(root \*TreeNode) []int {
    var result []int
    current := root
    for current != nil {
        if current.Left == nil {
            // 没有左子树，访问当前节点
            result = append(result, current.Val)
            current = current.Right
        } else {
            // 找到左子树的最右节点（前驱节点）
            predecessor := current.Left
            for predecessor.Right != nil && predecessor.Right != current {
                predecessor = predecessor.Right
            }
            
            if predecessor.Right == nil {
                // 建立线索
                predecessor.Right = current
                current = current.Left
            } else {
                // 恢复树结构，访问当前节点
                predecessor.Right = nil
                result = append(result, current.Val)
                current = current.Right
            }
        }
    }
    return result
}
```

## 示例演示

让我们以示例1 `root = [1,null,2,3]` 为例：

```
    1
     \
      2
     /
    3
```

### 递归法执行过程：

1. `inorder(1)` → 调用 `inorder(null)`（左子树）→ 返回
1. 添加 `1` 到结果
1. 调用 `inorder(2)`
   - `inorder(2)` → 调用 `inorder(3)`
     - `inorder(3)` → 调用 `inorder(null)` → 返回
     - 添加 `3` 到结果
     - 调用 `inorder(null)` → 返回
   - 添加 `2` 到结果
   - 调用 `inorder(null)` → 返回

最终结果：`[1, 3, 2]`

| 3 | 1 (弹出) | [] | [1] |
| 4 | 2 | [2] | [1] |
| 5 | 3 | [2, 3] | [1] |

## 答案有效性证明

✅ **正确性证明：**

1. **递归法**：严格按照中序遍历的数学定义实现，先左后根再右，符合要求。

1. **迭代法**：通过栈模拟递归调用过程。每次都将左路径上的所有节点入栈，确保左子树被完全处理后再处理根节点，然后处理右子树。

1. **Morris遍历**：通过建立临时线索，确保每个节点都能被正确访问一次，且在访问完成后恢复原始树结构。

✅ **边界情况验证：**

- 空树：返回空列表 ✓
- 单节点：返回包含该节点值的列表 ✓
- 只有左子树：正确按中序访问 ✓
- 只有右子树：正确按中序访问 ✓

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|------------|------------|------|
| 递归法 | O(n) | O(h) | h为树的高度，最坏O(n)，最好O(log n) |
| 迭代法 | O(n) | O(h) | 栈空间，同递归法 |
| Morris遍历 | O(n) | O(1) | 只使用常数额外空间 |

**时间复杂度说明：** 每个节点都被访问恰好一次，所以时间复杂度为 O(n)。

**空间复杂度说明：**

- 递归和迭代法的空间复杂度取决于树的高度
- Morris遍历通过修改树结构避免了额外空间，但会暂时改变原树结构（最后会恢复）

## 问题总结

📌 **关键要点：**

- 中序遍历的核心是 **左→根→右** 的访问顺序
- 递归法最简洁易懂，是首选方案
- 迭代法有助于理解遍历的本质，面试常考
- Morris遍历空间效率最高，但实现复杂，一般了解即可

💡 **应用场景：**

- 二叉搜索树的中序遍历结果是有序的
- 用于验证二叉搜索树的有效性
- 树的序列化和反序列化

❌ **常见错误：**

- 混淆前序、中序、后序的访问顺序
- 迭代法中忘记处理右子树
- 边界条件处理不当（空树、单节点）

✅ **最佳实践：**

- 理解每种方法的时间空间权衡
- 掌握如何将递归思路转换为迭代实现
